# Simulation — Cameroon SmartTrip

## Objectif

Les **profils utilisateurs** sont simulés.
Les hôtels, transports, activités et tarifs restent ceux du projet.

## Résultats pré-calculés

- Profils simulés : 24
- Plans respectant le budget : 75.0%
- Coût moyen des plans : 176,188 FCFA

### Hôtels les plus sélectionnés

- Résidence Ketty Sina: 16 sélection(s)
- Hôtel Les Polygones: 5 sélection(s)
- Complexe Hôtelier MAJEO By J&D: 2 sélection(s)
- Hôtel Lobé: 1 sélection(s)

### Classes de transport les plus sélectionnées

- MasterClass Plus: 13 sélection(s)
- Business Class: 10 sélection(s)
- MasterClass S: 1 sélection(s)

## Stress test

Le fichier `simulation_results/stress_test_budget.csv` teste le même profil sur plusieurs budgets pour observer :
- le seuil de faisabilité ;
- les changements d'hôtel ;
- les changements de transport ;
- les ajustements d'activités ;
- le budget restant.
